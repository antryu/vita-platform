# VITA Platform — Project Instructions

## Project
VITA Platform: VitalRing 데이터 기반 AI 헬스케어 플랫폼 웹사이트
- 본사(ZTAcom) 협상용 제안서 + 파트너 소개 + 라이브 데모 + 사업계획서

## Tech Stack
- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS + shadcn/ui + lucide-react + framer-motion
- Design: Premium healthcare, navy/teal primary, glassmorphism, NO emojis in UI

## Permissions
- Subagents may read/write all files in this project directory
- Subagents may run bash commands for this project (npm, build, etc.)

## Conventions
- Korean text for UI content, English for code
- Components in /components/, pages in /app/
- Use shadcn/ui components where applicable
- Use framer-motion for page animations
- Color scheme: vita-teal (accent), vita-navy (primary dark), vita-coral (alerts), vita-gold (premium)
